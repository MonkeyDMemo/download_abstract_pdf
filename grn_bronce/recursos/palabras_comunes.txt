# Es entrada de la regla `sensible_mayusculas` de la seccion 2 del contrato:
# si alguna superficie de una fila, en minusculas, aparece aqui, esa fila

# tiene dos clausulas, y la otra es la longitud: tres caracteres o menos.

# Medido sobre `etapa2/genes_pao1.tsv`: 181 filas sensibles, **181 por la
# clausula de longitud y 0 solo por esta lista**. Las 41 entradas tienen tres

# CORREGIDO EL 27 DE AGOSTO: LO DE ARRIBA ERA FALSO
# =================================================
#
# Este archivo decia que de las 1931 superficies de cuatro caracteres o mas
# **ninguna es una palabra inglesa**, y que anadir palabras largas seria
# inerte. Las dos cosas eran falsas, y el error de razonamiento es preciso: se
# comprobo si la superficie TAL COMO SE ESCRIBE --`folD`-- es una palabra
# inglesa, y no lo es. Pero el emparejamiento es insensible a mayusculas, asi
# que lo que importa es si **su forma en minusculas** lo es.
#
# Son cuatro, y tres son palabras centrales de esta literatura:
#
#     folD -> "fold"   1166 menciones, 1151 en minuscula ("3-fold increase")
#     hemE -> "heme"    123 menciones, 118 en minuscula (hierro, sideroforos)
#     pilI -> "pili"    136 menciones, 115 en minuscula (motilidad, virulencia)
#     minD -> "mind"    sin impacto medido, pero la colision es la misma
#
# `folD` llego a ser **el segundo blanco mas citado de toda la tabla de
# evidencias**, solo detras de `lasR`, con el 88% de sus oraciones trayendo el
# patron "N-fold" o "fold change". Entre los cuatro sostenian 191 aristas de
# 8653, y 51 de ellas estaban en el estrato de mayor confianza.
#
# Lo encontro el muestreo para medir precision, antes de que nadie juzgara una
# sola fila: la arista `AlgU -> folD` traia 16 articulos de respaldo y ninguna
# de sus tres oraciones de evidencia mencionaba el gen.
#
# La leccion para quien lea esto: **la comprobacion hay que hacerla sobre la
# cadena con la que se compara, no sobre la que se escribe.** Es el mismo error
# que el verificador de fuga que media con la clave del agrupamiento.
#
# `construir_diccionario.py` imprime en cada corrida las dos cifras («filas
# sensibles: N por longitud, M solo por palabras_comunes.txt») para que nadie
# tenga que deducir a mano si esto esta haciendo algo. El contrato exige el
# archivo y exige poblarlo con las veinte palabras de abajo, asi que se
# conserva; lo que se quita es la impresion de que aqui hay una defensa
# activa. Lo que si hace cada linea es dejar escrito POR QUE ese gen de tres
# letras es un riesgo, que es informacion que la clausula de longitud no da.
#
# Medido en 60 documentos del corpus, reconocimiento insensible contra
# sensible: cat 38 vs 2, his 47 vs 3, fur 32 vs 13, map 70 vs 44, sec 16 vs 8,
# ser 7 vs 0, leu 4 vs 0. La diferencia son falsos positivos puros. Ese es el
# dano que la sensibilidad evita, y lo evita por longitud.
